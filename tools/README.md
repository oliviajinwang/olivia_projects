## Update local PATH

1. Open Search: Press the Win key and type "Env".
1. Select: Click on "Edit the system environment variables".
1. Environment Variables: In the window that pops up, click the Environment Variables button at the bottom right.
1. Edit Path:
   Under User variables (for just you) or System variables (for everyone), find the variable named Path.
    Select it and click Edit.
1. Add New Entry:
    Click New on the right side.
    Paste the folder path you want to add (e.g., C:\Python312\Scripts).
1. Save: Click OK on all three windows to save your changes.

VSCode may cache old path. After updating PATH, close VSCode and restart.
